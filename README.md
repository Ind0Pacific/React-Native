# 🎯 Goal Tracker App

A simple, lightweight React Native mobile application built with Expo that allows users to capture, track, and manage their personal goals on the go.

---

## 📱 Features

- **Add Goals:** Quickly type and submit new goals using an interactive input field.
- **Scrollable List:** Easily view all added goals in a clean, scrollable interface.
- **State Management:** Uses React Hooks (`useState`) to handle real-time user input and updates dynamically.
- **Cross-Platform:** Built with React Native to work seamlessly on both **Android** and **iOS**.

---

## 🛠️ Built With

* [React Native](https://reactnative.dev/) - Mobile framework
* [Expo](https://expo.dev/) - React Native development toolchain
* [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - Application logic
